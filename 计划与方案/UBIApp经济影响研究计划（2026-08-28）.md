# UBIApp 经济影响研究计划（2026-08-28）

> 猫灯命（2026-08-28）：「关于基本收入应用，UBIAPP，现在我们研究一下他经济上的影响，你设计一份研究计划，列明可能的影响方向。」

## 一、UBIApp 机制基线（影响分析的出发点）

| 机制 | 内容 |
|---|---|
| 额度直达 | 数字人民币直发个人账户、不被截流、统一入口——「货币流版本的先行者」（第12章） |
| 额度三条 | 月度重置、不可累积、不可提取转账——「一张按月刷新的生活券，不是第二份工资」（技术计划书） |
| 用途限定 | 额度只行使生活资料购买权，生活资料类目限定——货币功能分化的技术载体 |
| 国有供给五件套 | 自动化消费品工业、公共住房、公共交通、基本消费品商店网络、公共算力——「基本收入管买得起，国有供给管买得到」；公共供给平价是市场价格基准 |
| 政治本质 | 规则代码化＋裁量权清零＝篡夺官僚整体的权力——共产主义的起点，社会主义的终点（第12章） |
| 配套 | 金税四期以数治税（异常自动识别率99.2%）、双层审计（第二道闸门）、小额匿名分级（隐私与防套利并存） |
| 国际版 | PPP 基准人均每月约500美元、双币制、智能终端登记、储备活化循环（境外额度→买中国商品→外汇回流→买原材料） |

### 三、产业与自动化（两条雇佣链的传导）

| 方向 | 机制一句话 | 对照指标 |
|---|---|---|
| 7. 自动化加速器 | 退出机制倒逼自动化变划算，成本交叉点提前（「退出机制是自动化的加速器」） | 自动化投资增速（正典三组之一） |

| 9. 产业结构出清 | 打击顺序三段：首当其冲＝基于廉价劳动力运行的劳动密集型产业（纺织／服装／制鞋／组装）——竞争优势是「谁家的人更便宜」，UBI 抬高保留工资即掀翻成本结构；出口三个死路两条：倒逼改造（阵痛最短）、转嫁价格（压向通胀锚定）、转移越南印度分层看待（2026-08-29数据验证修正：缝制环节转移真实发生——服装出口份额十年降9pp、对美份额39.7%→21.6%，但供应链中枢未失——越南面料67%、纱线68-71%依赖中国，转移＝中间品出口，升级＝面料上游化，纺织品份额43.3%创新高）；中国有完整产业链土壤（上游设备下游市场都在国内）。其次＝服务业（餐饮／家政／零售／快递／外卖）：同样基于廉价劳动力但无法转移（就长在本地市场），只能就地提价或自动化；机制分两阶段——现状是先吸收再内卷（制造业流出劳动力涌入服务业压价：骑手1590万、注册运力为实际需求5.4倍、配送费腰斩收入-35%），短缺抬价在 UBI 生效、退出权落地后才显现；服务业是无产阶级自服务（比价冲突：待遇提升＝工农雇工支付更高报酬，工农工资也在涨故可部分消化）。末位＝资本密集型与技术密集型：人力成本占比低、受影响较小，技术密集型还受益于市场规模扩大；但利润依然四路削减——议价权上升的工资谈判、额度撬动的竞争加剧、以数治税封死逃税空间、金融化褪色（金融资本是死敌） | 劳动密集型利润率、服务业用工荒程度、企业迁移、各行业利润率分化 |
| 10. 受益与受损行业分化 | 技术计划书已有受益四类／受损四类清单的实证检验 | 行业增加值分化 |

### 八、国际（购买力平价的传导）

**组内总纲一（猫灯定，2026-08-29）**：历史上对劳动者让利的努力（工厂法、新政、福利国家、劳动合同法）均以资本逃离为终止——资本逃往能逃离的区域（去工业化、离岸外包、避税天堂），局部让利注定被套利掏空。让利的持久性要求管控的全球性：对资本的管控必须管控到他们无法逃离为止，管控的边界必须与逃离的空间重合。由此推导：**完成世界革命正如扩展世界市场一样，是不可避免的政治经济学要求**——资本增殖要求不断扩展市场（斯密定理与卢森堡外部市场的资本版），退出权存续要求不断扩展管控（世界革命是任何让利政策的完成条件）。单边让利＝百草枯，全球让利＝圈禁；圈禁的栅栏＝温水机制、世界编户、金税四期与武力背书。

**组内总纲二：熵增与负熵输入（猫灯定，2026-08-29）**：福利国家的不可维持，根源在资本的主动逃离与主动拆解——论证不可持续性要指认机制，不能复读结论。社会主义国家本身也是福利国家（为劳动者提供保障的广义福利国家），客观上同样是不可持续的中间状态：长久存续必面对资本侵蚀（外部）与内部腐化（内部）——与定性论自洽：过渡性不是时间问题，是熵的问题。政治结构与任何封闭结构一样，是熵增的；维系熵减的秩序存在，必须依赖外部资源输入（负熵）。负熵输入只有两条路：对外掠夺（法西斯式阶级调和：对内福利靠战争红利与存量外民族，有限且自我消耗，长远不可持续）与全球协作治理（负熵来自生产力本身）。同样的熵增发生在中国之外：从美国到欧洲，一律如此。**世界治理这个任务客观存在而且不可逃避**——局部秩序必被资本逃离掏空或崩溃，秩序只能在全球尺度建立；不走全球治理，就退向资本主义或法西斯化。

**组内总纲三：两次过渡的历史对称（猫灯定，2026-08-29）**：封建到资本主义，资本主义瓦解了人身依附，将劳动力从政治命令下征发的徭役变成了自由流动的市场商品——但马克思看穿了解放的另一半：双重自由的工人，自由得一无所有；摆脱依附的自由同时是失去生产资料的自由。每次生产方式更替都更换一次强制机制（形态论双判据的强制机制轴）：封建＝人身强制，资本＝饥饿强制，共产＝无强制（退出权）。两次过渡的操作对称：第一次瓦解领主对人身依附的控制（赶人入市场），第二次瓦解资本对流动性的特权（圈禁资本）——**圈禁不是反常操作，是历史过渡的常规动作**，正像瓦解人身依附才能建成劳动力市场，圈禁资本才能建成退出权的世界。连圈地都有对称：圈地运动是资本对劳动力的圈禁史（赶农民进劳动力市场，「自由流动的商品」的诞生仪式），圈禁资本是劳动者对资本的圈地（把资本从套利空间赶回生产力，「自由退出的人」的诞生仪式）——历史的两次圈禁，第一次圈的是人，第二次圈的是资本，方向相反，性质同一。

**组内收束（猫灯定，2026-08-29）**：资本主义到社会主义的变化，区别在政权的主导权：资本主导的市场中，劳动力的出售者没有议价资格（供给永远过量，议价权为零），只能服务于资本的再生产；无产阶级主导的市场中，劳动力掌握议价权，可以自行选择资本的再生产方向、享受资本的红利——「资本是马，市场是路，所有制是鞍」的精确化：骑手从资本换到劳动。但资本尽管受控于劳动，其逐利本性依然指导着再生产——它一定要流动到劳动力没有议价权的地方去，**即使是被控制着，它也要尝试**（社会主义国家同样躲不过逃离，改革开放后的资本照样流向越南印尼）。逐利本性不可改造（资本的存在方式就是增殖的本能），只能结构性约束（圈禁），不能劝说性改造。这就给出社会主义向共产主义发展的完整内容：**统一全世界、推行世界治理、将资本圈禁**——三件事是一件事的三个说法，圈禁就是退出权的世界普及，世界革命就是圈禁的完成形态。社会主义骑在马上（不杀马），马一直想跑（逃离的本性）；要么拴缰圈禁走向共产主义，要么被逃离掏空退回资本主义——中间状态里没有安稳，这是定性论的最后一块补丁。

## 三、对照指标总表

**正典三组**（论文 L287，预言对照的原始承诺）：
1. 各地工资下限的趋同度（方向22）
2. 自动化投资的增速（方向7）
3. 产业迁移的方向（方向25）

**扩展指标**（变法上书计划四指标：工资下限趋同度、自动化投资增速、生育率、试点数据；本计划扩展）：消费率、平台抽成、房租指数、通胀率（CPI 与国有平价偏差）、劳动参与率、消费信贷余额、审计覆盖率、美元指数。
