## 一、工程定位

《社会主义论》第二篇（历史）的实践总结工程。现有历史篇三章（演进逻辑／总史论／众意论）立的是史观与五百年账，本工程补的是**实践解剖**：社会主义与资本主义各标本的经验教训的系统总结。

成果形态：拟为《社会主义论》新篇《实践总结篇》（位置在第二篇历史之后、第三篇经济学批判之前），以共性个性对照表与矛盾演变线为主体；提炼出的通则按语域分工入论文（学术版）与宣言（煽动版），猫灯审定后执行。

理论落点：既有四大理论的实践证据补全——
- 六代治理体系（祀戎分配）：每一代体系死因的实证解剖
- 五世同死于分配：郑和标本之外的更多标本
- 剩余价值路径论：各标本的剩余价值流向与用途
- 范畴生命史：各标本在形态演进史上的位置

## 二、对象清单

**社会主义实践标本（七个）**：

| 标本 | 时段 | 解剖重点 |
|---|---|---|
| 苏联 | 1917-1991 | 标本之王：战时共产主义→新经济政策→斯大林模式→停滞→解体；官僚阶级的生成与叛卖 |
| 东欧 | 1945-1991 | 移植模式的适应与失败：波兹南、匈牙利、布拉格之春、团结工会 |
| 南斯拉夫 | 1945-1991 | 自治社会主义实验：工人委员会、市场社会主义的边界 |
| 古巴 | 1959- | 小国孤岛生存：封锁下的坚持与特殊时期 |
| 越南 | 1975- | 革新开放：社会主义国家的市场改革另一例 |
| 柬埔寨 | 1975-1979 | 极端标本：波尔布特的空想与屠杀——革命过火的极限 |
| 新中国 | 1949- | 主力标本：前三十年（一化三改/大跃进/文革）→改革开放→新时代；论文5.5已立中国之路，本工程补完整实践史 |

**资本主义实践阶段（五个）**：

| 阶段 | 时段 | 解剖重点 |
|---|---|---|
| 自由竞争资本主义 | 18C-1870s | 原始积累、工厂制度、经济危机周期 |
| 垄断资本主义与帝国主义 | 1870s-1945 | 两次大战、殖民体系、大萧条 |
| 战后黄金三十年 | 1945-1973 | 凯恩斯主义＋福利国家——苏联竞争压力下的自我修正（退出权低配版） |
| 新自由主义四十年 | 1979-2008 | 金融化、去工业化、债奴化；福利国家的拆解 |
| 自动化时代 | 2008- | 赛博朋克趋向、马斯克UHI、AI驱逐劳动 |

**中间形态**：北欧社民福利国家（退出权低配版的现役样本）、罗斯福新政（苏联镜子）、凯恩斯主义（止步分配门外）。

## 三、分析方法（猫灯定）

1. **共性提炼**：每个标本走利益分配四入口——生产资料归谁、劳动由谁组织、产品与剩余如何分配、分配规则由谁解释
2. **个性分析**：每个标本的矛盾特殊结构（国情、起点、国际环境）
3. **矛盾主次分析**：主要矛盾与次要矛盾的地位变化、互相影响互相作用——用矛盾论的方法（论文2.3已引《矛盾论》[14]）；每个标本画一条矛盾演变线（矛盾在何时易位、易位的结果是什么）
4. **对照产出**：共性个性对照表（七标本×五阶段）、主要矛盾演变表、死因对照表（接五世同死于分配）
