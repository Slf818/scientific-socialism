# 实践经验总结工程-组织论评判框架（2026-08-29）

> 猫灯命（2026-08-29）：「以组织论为纲，苏联标本打头」开实践经验总结工程。本框架是工程的纲——以 理论存档/共产主义组织论（2026-08-29）.md 的三条线与五刻度为判据，七标本×五阶段逐标本检验。工程计划见 实践经验总结工程计划（2026-08-23）.md。

## 一、三条线（组织方式／规模／寿命）

**黏合剂线（组织方式）**：每标本的黏合剂检查——忠诚（依附）／分润（同利）／热爱（同好同志）哪个主导；黏合剂变质的路线：同志→依附→分润（倒退回组织方式三形态的旧格）。检查项：荣誉动员（劳动竞赛类）、同志纪律（批评与自我批评类）、依附化（干部对上级的人身忠诚）、分润化（特权集团、影子经济）。

**生产资料线（组织规模）**：每标本的生产资料掌握形态——配置权（政权）／所有权（资本）／零（无产）。社会主义标本的专门检查：**配置权→所有权的漂移**——生产资料的配置权被官僚集团私用变现的程度（官僚资产阶级转化论的操作化）。

**五样线（组织寿命）**：愿景／同好／荣誉／责任／退出权五样齐全度。三个重点残缺项：愿景枯竭（口号化、官话化——旗号与实质脱节）、退出权缺失（无退出机制的制度形态：户籍绑定、住房绑定、单位绑定——人身依附的社会主义版）、责任变质（终身制——可替代缺失，责任岗位变依附据点）。

## 二、五刻度（话语与制度的对应）

| 刻度 | 资本主义态 | 共产主义态 | 社会主义标本的检查项 |
|---|---|---|---|
| 旗号 | 利润 | 愿景 | 旗号与实质一致度——预言对照下旗号是否经得起检验 |
| 配给 | 所有权 | 证明权 | 配给方式的三岔路：证明权（规则公开）／裁量（官僚特权）／所有权（市场回归） |
| 身份 | 交易身份 | 成员资格 | 成员资格的分割程度——城乡二元、单位内外、特供体系 |
| 名义 | 价格 | 需要 | 分配名义的漂移——需要→劳动→价格的方向与程度 |
| 落实 | 买断 | 到账 | 利益落实的范围——落实到每个成员还是停留在名义（集体化式的名义公有） |

## 三、变质的总机制

社会主义组织是同志组织，但它运行在资本社会里（无产阶级主导的资本社会——定性论）——资本的逻辑（分润、交易、所有权）不断侵蚀同志组织的黏合剂与配给方式。防变质的三件套：两道闸门（货币功能分化＋双层审计）＋可替代不可积累＋退出权。**每一条制度设计都是对一类失败的直接回应**（逆向验证表见下）。

配给方式的专门论断：证明权缺位时，配给只有两条坏路——退回裁量（苏联：计划配给官僚化）或滑向所有权（市场改革：分润逻辑回归）。**没有第三条路，正是社会主义的两难；证明权配给（规则代码化＋账目公开）是破两难的正解。**

## 四、逆向验证表（失败经验→制度设计）

| 失败经验 | 对应的制度设计 |
|---|---|
| 苏联配给者型官僚（特权消费、影子经济） | 规则代码化＋裁量权清零（额度直达） |
| 干部终身制（责任变依附） | 可替代（任期、罢免、审计） |
| 特权积累（影子经济） | 不可积累（额度三条＋货币功能分化） |
| 集体农庄无退出权（人身依附的社会主义版） | 退出机制（额度保障退出权） |
| 愿景空洞化（官话） | 三件证明（可证伪的预言对照） |
| 账目黑箱 | 双层审计＋账本公开 |
| 计划需要被官僚垄断（以计划需要的名义自肥） | 需要判定规则化（公共核算） |
