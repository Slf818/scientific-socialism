## 二、踩过的坑（教训归档）

1. **真名入 Git 历史后清除成本高**：commit 一旦推送，删仓库是唯一干净清法——公开仓库署名必须第一次就定对（教训：发布前先定署名，不中途改名）
2. **rmSync 删不掉 Git 只读文件**：Windows 上 .git 对象文件只读，node fs.rmSync 失败——用 PowerShell Remove-Item -Force 可删
3. **mv 中文目录名在 Git Bash 编码乱**：用 node fs.renameSync 处理中文路径
4. **分类器对隐私的保护是对的**：暂存含家庭信息的 jsonl 时被数据外泄规则拦截——分类器替爱特拦下了猫灯已决定不上传的内容；分类器超时（deepseek-v4-pro 临时不可用）时写操作全部受阻，读操作正常
5. **gh repo delete 需要 delete_repo scope**：默认 token 无此权限——网页删除或 gh auth refresh 授权
