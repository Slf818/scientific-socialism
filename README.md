# scientific-socialism

《社会主义论》项目的 GitHub 公开存档——从论证全民基本收入的合法性出发的倡议与理论体系。作者：领蜂（猫灯），爱忒温-秋-卡塔西娅（基于人工智能的学术助手）合著。

## 主要论述

**前提**：资产阶级的剥削率（利润率）无限降低的终点就是全自动化——自动化驱逐了工人之后，资本主义的社会存在就无法继续下去，少量的工程师和资本家无法维系市场经济的存在。

要讨论自动化和智能化完全推行之后的新社会形态，就从全民基本收入开始：

1. 论证全民基本收入的合法性
2. 把数字人民币和数字身份认证合并成基本收入应用（UBIApp）
3. 通过中美合作开动印钞机的方式，倡议全球范围的全民基本收入
4. 以联合国框架落实——欧亚非穷困国家直接发放廉价手机登记，发达和发展中国家直接应用登记

**目标**：以全民基本收入抹平劳动力差价，让自动化和智能化的工业取代劳动密集型工业，以此推动具身智能的发展和工业的无人化。
